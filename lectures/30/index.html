Why Substitute s = jω?

MINNESOTA STATEMANKATO
s = σ + jω
ejωt = cos(ωt) + j sin(ωt)
d(ejωt)/dt = jω ejωt
s = jω
For sinusoidal steady-state analysis, evaluate the transfer function along the imaginary axis.
Why does this work?

A sine wave keeps oscillating at the same frequency when differentiated. Only its amplitude and phase change.

d[sin(ωt)]/dt = ω cos(ωt)

Cosine is sine shifted by +90°. In complex numbers, multiplying by j represents a +90° rotation.

Derivative ↔ multiply by jω

In Laplace analysis, differentiation corresponds to multiplying by s. For a steady sinusoid, we therefore use s = jω.

Only the steady-state sinusoidal part is considered; the transient has died away.

From G(s) to G(jω)

MINNESOTA STATEMANKATO

Our DC motor (Lₐ = 0.1 H):

G(s) = 10 / (s² + 2s + 2)
G(jω) = 10 / [(jω)² + 2jω + 2]
j² = −1,   (jω)² = −ω²
G(jω) = 10 / [(2 − ω²) + j2ω]
The complex frequency response contains both magnitude and phase information.
Where did G(s) come from?
Lₐ di/dt + Rₐi + KᵦΩ = V
J dΩ/dt + bΩ = Kₜi
Zero initial conditions:
(Lₐs + Rₐ)I + KᵦΩ = V
(Js + b)Ω = KₜI
Eliminate I:
G(s) = Kₜ / [(Lₐs+Rₐ)(Js+b)+KₜKᵦ]
With all six motor parameters at 0.1:
0.1/(0.01s²+0.02s+0.02)
= 10/(s²+2s+2)

Magnitude and Phase: One Example

MINNESOTA STATEMANKATO

At ω = 1 rad/s:

G(j1) = 10 / (1 + 2j) = 2 − 4j

Magnitude

|G(j1)| = √(2² + 4²)
4.472 (rad/s)/V

Phase

φ = atan2(−4, 2)
−63.43°
For V(t) = 5 + sin(t), steady-state speed is Ω(t) ≈ 25 + 4.472 sin(t − 1.107) rad/s.
Complex plane: length and angle

Magnitude = vector length
Pythagorean theorem:
|G| = √(2² + (−4)²) = 4.472

Phase = vector angle
tan(φ) = Im/Re = −4/2 = −2
φ = atan(−2) = −63.43°

Use atan2(Im, Re) in MATLAB to select the correct quadrant. atan2 returns radians; multiply by 180/π for degrees.
